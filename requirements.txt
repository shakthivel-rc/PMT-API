# The one upgrade that was not routine: fastapi 0.115.11 -> 0.141.1, needed because
# 0.115.x caps starlette below 0.47 and every starlette advisory is fixed at 0.47.2 or
# later. 0.141 wraps each `include_router` call in a `fastapi.routing._IncludedRouter`
# rather than flattening its routes into `app.routes`, so anything that ENUMERATES routes
# by walking `app.routes` sees only a handful and reports success over an almost empty
# set. That silently blinded `tests/unit/test_route_inventory.py` — the gate that asserts
# every private route answers 401. The traversal now lives in one place,
# `tests/route_walk.py`; use it rather than writing a second one.
